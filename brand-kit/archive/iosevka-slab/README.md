# yRisk brand kit

> **Archived 2026-08-28.** This Iosevka Slab direction is retained for
> provenance only. The official identity now lives at the root of
> [`brand-kit/`](../..).

yRisk uses a deliberately plain text identity: **`yRisk`** set in a precise
monospace, surrounded by generous whitespace. The restraint is the brand.

## Core direction

- Wordmark: `yRisk`
- Typeface: Iosevka Slab Extended Regular
- Tracking: subtly tightened from the font's native monospace spacing
- Primary ink: `#090909`
- Paper: `#F5F4F0`
- Reverse: `#FFFFFF`
- Decoration: none

[Iosevka](https://github.com/be5invis/Iosevka) is released under the SIL Open
Font License 1.1. This kit uses the Slab Extended Regular face for a sharper,
editorial monospace character. The font software is not distributed in this
directory. The supplied SVGs use outlined logo glyphs, so they preserve the
intended appearance without the font installed. The PNG exports are also ready
to use as-is.

## Usage

- Prefer the black wordmark on white, transparent, or paper backgrounds.
- Leave clear space around it equal to the height of the capital `R`.
- Do not add an icon to the wordmark, recolour individual letters, use a
  gradient, add a shadow, or place it inside a decorative badge.
- Use the full wordmark whenever there is enough horizontal room.
- Use `yR` for square avatars and `y` only at favicon scale.
- Keep the original casing. Do not change `yRisk` to `YRisk`, `YRISK`, or
  `yrisk` in the logo.

## Minimum sizes

- Full wordmark: 96 px wide on screen
- Avatar: 32 × 32 px
- Favicon: 16 × 16 px

## Export notes

The SVG files are the editable masters. PNGs are convenience exports. When
making a new asset, use Iosevka Slab Extended Regular and preserve the original
tracking, spacing, and colours.
